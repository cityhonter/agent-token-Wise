# Token-Wise（省 token 不降智）

让 AI 编码/对话更省钱，同时不降低输出质量。面向 Claude Code / CodeBuddy / Cursor 等支持 SKILL.md 的 agent。

> 一句话：**省 token 的正确姿势是"少带无关的东西"，不是"把该带的东西压缩"。**

## 解决的问题

| 痛点 | 本 skill 的解法 |
|---|---|
| 僵尸会话：一个会话干多件事，历史全是噪音，每轮白烧 token 还降智 | 上下文卫生模块：任务切换检测、/clear 建议、阈值预警 |
| 输出废话多：寒暄、过程叙述、"Certainly! I'd be happy to…" | 输出纪律：禁寒暄、diff-only、默认简版 |
| 模糊提问导致全仓扫描 | 输入瘦身：强制精确引用（文件+符号+行号） |
| 全量代码塞上下文，又贵又降智 | 索引地图协议（AI_INDEX.md）+ 按需精读 |
| 为了省钱把上下文压缩/模型降档，结果变笨 | **分级闸门 L0/L1/L2**：有损手段默认关，按任务类型放行 |
| 复杂任务一路狂奔写错方向，返工烧更多钱 | 红线 R4：先规划后执行（模式二） |

## 核心设计：无损优先 + 有损分级

- **L0 无损层（永远开）**：删冗余、缓存友好排序、精确引用、索引地图、subagent 隔离
- **L1 轻度有损（按档位）**：输出压缩、summary 型历史管理
- **L2 重度有损（默认关）**：/compact 全量压缩、模型降档、关思考

保护名单（`protected_tasks`）：架构设计、大规模重构、疑难 bug、教学、安全审查——这些任务**永不进 L2**。

## 安装

将 `token-wise/` 目录放到 agent 的 skills 目录：

- **Claude Code**：`~/.claude/skills/token-wise/`
- **WorkBuddy / CodeBuddy**：`~/.workbuddy/skills/token-wise/`
- 其他支持 SKILL.md 的 agent：按各自约定放置

## 配置

只改一个文件：`token-wise/config/token-wise.config.md`

1. **三档预设**：`preset: conservative / balanced / aggressive`
2. **模块开关**：输出纪律、输入瘦身、上下文卫生、思考控制、路由——每个都能独立开/关/调参
3. **红线提醒开关**：见下节

## 红线守则（重要，请务必阅读）

本 skill 内置 4 条红线，**行为级约束不可关闭**：

| # | 红线 | 为什么 |
|---|---|---|
| R1 | 不轻易切窗口（新会话） | 切新会话 = 缓存清零 + 上下文丢失，全价重来 + 理解偏差风险最高 |
| R2 | 不过缓存时间（TTL）对话 | 缓存过期后要交一次"全价重置税"；任务中断只要在同一会话内继续，缓存未失效（TTL 内） |
| R3 | 做好索引地图 | 全量代码 = 输入爆炸 + 上下文太满导致模型"迷失在中间"；索引便宜 1~2 个数量级 |
| R4 | 先规划后执行（模式二） | 把不确定性在纸面上消化掉，省掉"错误实现的全部成本" |

> **温馨提醒（R2/R3）**
> - 缓存 TTL 因厂商而异：Claude 系约 5 分钟（可扩展）、OpenAI 系约 5 分钟~1 小时、其余以官方文档为准。选型时查厂商定价页，不要盲信统一数值。
> - Codex、Claude Code、Aider 等主流工具已内置仓库索引（repo map），优先用工具自带能力；AI_INDEX.md 作为补充。
> - **任务中断后**：只要还在同一会话且未超 TTL，缓存与上下文都还在，直接继续即可，不要重开会话重来。

> **强烈建议：红线请你自己遵守，效果远好于依赖 agent 提醒。**
> 红线本身不可关闭，但可以关闭"提醒"——`config/token-wise.config.md` 中
> `redlines.reminders: false` 会让 agent 静默遵守、不打扰你。
> 适用于已经明白这些道理、不需要被反复提醒的用户。
> **请注意：关闭提醒不代表红线失效**，agent 的行为约束依然执行；
> 只有"是否主动啰嗦提醒"被关闭。

## 本 skill 自身的 token 成本

- 常驻加载：SKILL.md（约 1.5K token）+ config（约 1K token）。
- 按需加载：references/（决策树、提示词模板，每次几百 token）。
- 总常驻成本约 **2~3K token/会话**——这是"纪律型 skill"的固定开销。
- **极简模式**：只需要红线 + 输出纪律时，删掉 config/ 和 references/，单文件 SKILL.md 即可运行。

> 别让"省 token 的 skill"自己变成 token 大户——所以本 skill 刻意把细节都放进
> references 按需加载，SKILL.md 保持精简，并公开常驻成本让你有数。

## 会不会降智？

- 无损手段（L0）：永不降智，越用越省还更聪明。
- 有损手段（L1/L2）：默认关闭或分级放行；保护名单内任务永不降智。
- 最大的"降智"来源其实是**僵尸会话**——本 skill 的主战场正是治理它。

## 常见问题

**Q: aggressive 档会降智吗？**
A: 会，在某些任务上有风险。它允许 compact 和降档。如果发现质量下降，退回 balanced 或 conservative。

**Q: 配置写坏了怎么办？**
A: 删掉配置文件或用默认 preset，agent 会按默认值执行并提示。

**Q: 支持非 Claude 模型吗？**
A: 支持。router 模块留空即不干预模型选择，机制本身与厂商无关。
