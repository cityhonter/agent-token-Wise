# Token-Wise 配置文件

> 这是用户唯一需要编辑的文件。修改后保存即可，agent 会在会话中读取。
> 格式：YAML。注释以 `#` 开头。
> 冲突裁决：`protected_tasks` > 模块开关 > preset。

```yaml
# ============================================================
# 第 1 层：三档预设（大多数用户只改这里）
# ============================================================
# conservative 保守：只做无损手段，绝不压缩语义、不降模型、不动思考
# balanced     平衡：无损手段全开 + 输出纪律标准档 + 有损手段分级放行（默认）
# aggressive   激进：输出纪律严格档 + 允许 compact/降档（有降智风险，慎用）
preset: balanced

# ============================================================
# 红线守则
# ============================================================
redlines:
  # 红线本身不可关闭（R1~R4 行为级约束始终生效）。
  # 此开关只控制 agent 是否"主动提醒"：
  #   true  = 到触发点主动提醒用户，并给出原因（默认）
  #   false = 静默遵守，不打扰；仅在用户明确违反红线时给一句简短提示
  # 注意：即使关闭提醒，红线行为依然执行。
  # 强烈建议：红线最好由用户自己遵守（不轻易切窗口 / 不过缓存 TTL / 做索引 / 先规划后执行），
  #           效果远好于依赖 agent 提醒。
  reminders: true

# ============================================================
# 模块开关：输出纪律（省输出 token，无损）
# ============================================================
output_discipline:
  enabled: true
  # off=不启用  basic=只禁寒暄与复述  standard=+diff-only  strict=+默认简版/禁过程叙述
  strictness: standard
  # 改代码时只输出 diff，不输出解释
  diff_only: true
  # 默认回答详略：brief=简版（说"详细"才展开）  full=完整
  default_detail: brief

# ============================================================
# 模块开关：输入瘦身（省输入 token，无损优先）
# ============================================================
input_slim:
  enabled: true
  # 强制精确引用：文件路径+函数/符号+行号，禁止模糊请求（如"修复 auth 的 bug"）
  force_precise_ref: true
  # 索引地图协议：auto=有就用没有就建议  require=缺失时先生成再干活  off=不使用
  # 温馨提醒：Codex、Claude Code、Aider 等主流工具已内置仓库索引（repo map），
  #           优先用工具自带能力；AI_INDEX.md 作为补充（工具覆盖不到的语言/场景）
  index_map: auto
  # 宽范围检索/扫描丢给 subagent，结果只回摘要，不污染主上下文
  use_subagent_scan: true

# ============================================================
# 模块开关：上下文卫生（僵尸会话治理，省钱+防降智双收益）
# ============================================================
context_hygiene:
  # 触发 /clear 建议的上下文大小阈值（token）
  # 为什么默认 60K：超过这个量，agent 开始丢失早期的关键决定
  clear_hint_threshold: 60000
  # 触发压缩/收尾建议的阈值（token）
  # 温馨提醒：不同厂商/模型缓存 TTL 不同——Claude 系约 5 分钟（可扩展），
  #           OpenAI 系约 5 分钟~1 小时，其余以官方文档为准。
  #           本阈值只用于"上下文太大该收尾"的建议，与缓存 TTL 是两回事。
  compact_hint_threshold: 150000
  # 收尾时强制产出"进度小结+待办+下一步"（隔夜/切会话时防失忆+防缓存白烧）
  overnight_summary: true

# ============================================================
# 思考控制（有损，默认 auto 分级，禁止全局关闭）
# ============================================================
thinking:
  # auto=按任务复杂度给档位  max=复杂任务全开  off=不干预（不主动调）
  mode: auto

# ============================================================
# 任务分诊（路由：简单任务用便宜模型，复杂任务用旗舰）
# ============================================================
router:
  enabled: true
  # 留空 = 不干预模型选择（agent 用当前模型即可）
  heavy_model: ""   # 例：opus / claude-sonnet-4-5 / gpt-5
  light_model: ""   # 例：haiku / gpt-4.1-mini / deepseek-chat

# ============================================================
# 任务豁免表（禁压名单）：这些任务永远不进 L2，L1 仅限输出压缩
# ============================================================
# 为什么：这些任务的质量依赖完整推理链，压缩/降档/关思考 = 必降智
protected_tasks:
  - architecture_design        # 架构设计
  - large_refactor             # 大规模重构
  - tricky_bug                 # 疑难 bug 排查（同一问题修正>=2次自动进名单）
  - teaching                   # 教学/解释给新人听
  - security_review            # 安全审查
```
